# Canciones por sección - Distancia Cero

Mete aquí las canciones locales que quieras usar por sección:

public/audio/scenes/

Secciones disponibles:

- inicio
- propuesta
- contadores
- carta
- entrelazados
- historia
- universo
- cartas
- abrir-cuando
- playlist
- razones
- galeria-agujero-negro
- promesas
- distancia

Ejemplo:

.\scripts\agregar-cancion.ps1 -SectionId historia -FilePath "$env:USERPROFILE\Downloads\mi-cancion.mp3" -Title "Mi canción" -Artist "Artista" -Volume 0.7
